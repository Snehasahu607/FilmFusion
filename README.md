# FilmFusion – React Movie Discovery App

A responsive movie discovery web application built with **React, Vite, HTML and CSS**.

## Resume-aligned features
- Real-time movie search using React state.
- Favorites functionality with persistent in-session state.
- Genre, year and sorting filters.
- Dynamic UI rendered from reusable React components.
- Responsive layouts for desktop, tablet and mobile.
- Optimized rendering with `useMemo` for derived movie lists and `useCallback` for favorite handlers.
- Lazy-loaded poster images for smoother page loading.
- Movie details modal for quick discovery.

## Run locally
```bash
npm install
npm run dev
```

Open the local URL shown by Vite.
